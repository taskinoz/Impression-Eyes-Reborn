# ime-reborn website

Static Astro website for Impression Eyes Reborne.

```powershell
bun install
bun run dev
bun run build
```

The production site is configured for the GitHub Pages project path
`/Impression-Eyes-Reborne/`. Tagged application releases are downloaded from
the repository's `releases/latest` URL.

Before publishing, enable GitHub Sponsors for `taskinoz` or replace the
`support` URL in `src/pages/index.astro` with the preferred contribution page.
